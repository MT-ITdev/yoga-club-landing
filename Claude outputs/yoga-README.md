# Yoga Club — лендинг йога-центра

Одностраничный сайт для сети студий йоги в Москве. Адаптивная вёрстка на SCSS, анимации при прокрутке, интерактивное расписание занятий.

## Что реализовано

- анимированный hero-блок с мандалой и слоганом «Йога для тела и души в центре Москвы»
- блок «о клубе» со счётчиками (часы занятий, площадь студий, преподаватели, чашки чая в неделю)
- карусель преподавателей с переключением стрелками
- блок направлений (хатха, кундалини, термо-йога, аштанга) с ценами
- модальное окно с расписанием занятий по дням недели и формой записи
- блок с двумя студиями («на Мясникова» и «на Бумажной») и описанием каждой
- секция контактов с картой, адресами, телефоном и формой онлайн-записи
- модальное окно заказа обратного звонка, вызываемое из шапки сайта

## Стек

HTML, SCSS/CSS, JavaScript, jQuery, WOW.js (анимации при скролле)
